## Šta se svuda slaže
| Pravilo | Izvori |
|---|---|
| 4 igrača, 32 karte (7–A), po 8 karata, jačina A-K-Q-J-10-9-8-7, nema aduta | svi |
| Mora se pratiti boja; ko nema boju, baca bilo šta | pagat, legalbet, bigosaur |
| 28 partija (7 igara × 4), pobeđuje najmanje poena | pagat, legalbet, bigosaur |
| Maksimum −1 po štihu, Minimum +1 po štihu, Dame +2 po dami | pagat, legalbet, bigosaur |
| Herc +1 po hercu, ko uzme sve −8 | pagat, legalbet, bigosaur |
| Žandar tref +8 | pagat, legalbet, bigosaur |
| Slaganje: prva karta određuje rang za sve boje, niz naviše, posle keca 7 | pagat, legalbet, bigosaur, hu.wiki |
| U slaganju se mora odigrati karta ako postoji | pagat, hu.wiki |
| Igra se suprotno od kazaljke | pagat, hu.wiki |

## Varijante (izvori se razlikuju)
| Pitanje | Varijante | Naš izbor |
|---|---|---|
| Redosled igara | fiksan (pagat osnovno, legalbet) · bira igrač i svako bira svaku igru jednom (pagat varijanta, bigosaur) | **bira igrač**, zahtev korisnika |
| Delilac | deli 7 puta zaredom (pagat) · menja se svake partije (bigosaur „naizmenično“) | menja se svake partije |
| Kralj herc + … | poslednji štih +4 (pagat, legalbet) · **6. štih** +4 (bigosaur, pagat varijanta) | poslednji štih |
| „Dalje“ u slaganju | bez kazne (pagat osnovno, legalbet, bigosaur) · **+1 po „dalje“** (pagat varijanta, opusteno) · opusteno: „prvi izađe **bez tačke** −8“ = ko je rekao „dalje“ gubi −8 | **+1 i gubi −8**, pravilo korisnika, potvrđeno na opusteno |
| Žandar tref | +8 (većina) · +6 i +2 igraču preko puta (pagat varijanta) | +8 |
| Dodatno | „mala lora“ bez žandara; 4 dodatne partije po izboru (pagat) | nije uvedeno |

## Moguća proširenja (opcije sobe)
- „6. štih“ umesto poslednjeg u igri Kralj herc.
- Fiksni redosled igara (klasična Lora).
